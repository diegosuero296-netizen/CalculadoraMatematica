# Calculadora Matemática - Java

Autor: Diego Suero - 2025-2470

Aplicación de consola en Java con menú interactivo que realiza suma, resta,
multiplicación y división con dos números double. Usa switch, do-while y Scanner,
y valida la división por cero con un condicional if.

## Cómo ejecutarlo
Abrir el proyecto en NetBeans, abrir CalculadoraMatematica.java y ejecutar con Shift + F6.
